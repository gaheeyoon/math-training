# 가히의 하루 두 장 계산 트레이닝

초등 계산 연습을 웹에서 바로 풀고 그 자리에서 채점받는 학습 사이트입니다.
종이 워크북과 똑같은 문제를 담고 있어서, 밖에서는 휴대폰으로 풀고 집에서는 인쇄해서 풀 수 있습니다.

하루 분량은 **두 장**입니다. A는 가로셈으로 감각을 익히고, B는 세로셈으로 정확도를 다집니다.
A·B 두 장씩 열흘이면 한 회차가 끝나고, 열 회차면 한 학기 분량을 마칩니다.

```
https://yoongahee.com/math-training/
```

## 1. 먼저, 인증 코드를 받으세요

아무나 들어올 수 없도록 **주차별 인증 코드**로 잠겨 있습니다.

코드는 **블로그 댓글로 문의**해 주시면 알려드립니다.
댓글을 남겨 주시면 그 주에 쓸 수 있는 여덟 글자 코드를 답글로 드려요.

코드는 **매주 월요일에 바뀝니다.** 한 주가 지나면 다시 댓글로 문의해 주세요.
한 번 들어가면 그 주 일요일 밤까지는 다시 묻지 않으니, 일주일에 한 번만 받으시면 됩니다.

> 지난주 코드는 한 주 동안 더 받아줍니다. 월요일에 답을 조금 늦게 받으셔도 학습이 끊기지 않습니다.

## 2. 들어가기

사이트를 열면 코드를 묻는 화면이 나옵니다.
받으신 코드를 넣고 `들어가기` 를 누르세요.

코드는 `XXXX-XXXX` 형태의 여덟 글자입니다.
**소문자로 쳐도, 하이픈을 빼먹어도 알아서 맞춰 줍니다.**
헷갈리기 쉬운 `I` `O` `0` `1` 은 코드에 아예 들어가지 않으니 안심하세요.

---

## 3. 학기와 회차 고르기

들어가면 학기 카드가 보입니다. 지금은 **1학년 1학기**와 **3학년 1학기**가 열려 있고,
회색으로 흐린 카드는 아직 준비 중인 학기입니다.

학기를 고르면 열 개의 회차가 쭉 나옵니다. 회차마다 무엇을 배우는지와
지금까지 몇 장을 끝냈는지(`4 / 20장`)가 함께 표시됩니다.

각 회차에는 버튼이 두 개 있습니다.

- **원리 보기** — 그 회차의 계산 원리를 한 장으로 정리한 설명
- **연습하기** — DAY 1~10의 연습장 목록

학년에 따라 문제 모양이 다릅니다. 1학년은 가르기·모으기 막대, 덧셈표, 수의 순서표처럼
눈으로 보고 채우는 형태가 많고, 3학년은 가로셈과 세로셈이 중심입니다.

---

## 4. 하루 학습 흐름

**① 원리 한 장을 먼저 읽습니다.**
눈으로만 훑지 말고 맨 아래 '스스로 확인' 칸을 채우고 넘어가세요.
원리를 한 번 소리 내어 설명해 보면 그날 연습이 훨씬 수월해집니다.

**② A·B 두 장을 이어서 풉니다.**
같은 내용을 서로 다른 모양으로 묻습니다. 3학년은 A가 가로셈, B가 세로셈이고,
1학년은 A와 B가 각각 다른 방식으로 같은 개념을 확인합니다. 두 장을 같은 날 푸는 것이 좋습니다.

**③ 채점하고, 틀린 것만 다시 풉니다.**
전부 다시 풀 필요는 없습니다. 오답 서너 개만 그날 안에 다시 풀면 충분합니다.

**④ DAY 10에서 90점에 못 미치면 다음 회차로 넘어가지 않습니다.**
같은 회차를 한 번 더 반복하는 편이 결국 빠릅니다.

## 5. 문제 푸는 법

빈칸을 눌러 숫자를 입력합니다. 숫자만 들어가므로 다른 글자는 자동으로 걸러집니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 다음 칸으로 넘어가기 | `Enter` 또는 `Tab` |
| 바로 채점하기 | 마지막 칸에서 `Enter`, 또는 아래 **채점하기** 버튼 |
| 틀린 것만 다시 풀기 | 채점 후 **틀린 문제만 다시 풀기** |
| 처음부터 다시 풀기 | 채점 후 **전체 다시 풀기** |

화면 위쪽에 걸린 시간과 맞은 개수가 표시됩니다.
시간은 첫 칸을 누르는 순간부터 재기 시작하고, 채점하면 멈춥니다.

채점하고 나면 맞은 문제는 초록색, 틀린 문제는 붉은색으로 표시되고
틀린 문제 옆에 **정답**이 나옵니다. □가 있는 식에서는 정답과 함께
`□ = 42 ÷ 6` 처럼 **어떤 식으로 바꿔야 했는지**도 알려줍니다.

채점이 끝나면 아래에 **다음 장** 버튼이 생겨서 바로 이어 풀 수 있습니다.
**90점 이상**을 받은 장은 완료로 표시되어 진행률에 반영됩니다.

## 6. 종이로 풀고 싶을 때

화면에 보이는 대로 찍는 게 아니라, **종이 워크북과 똑같은 지면으로 다시 짜서** 인쇄합니다.
글자가 잘리거나 두 장으로 나뉘지 않고 A4 한 장에 정확히 들어갑니다.

| 어디서 | 버튼 | 나오는 분량 |
|---|---|---|
| 연습장 화면 | 오른쪽 위 **인쇄** | 그 장 하나 (A4 1장) |
| 원리 화면 | 위쪽 **인쇄** | 원리 한 장 (A4 1장) |
| 회차 화면 | 제목 옆 **이 회차 인쇄** | 표지 + 원리 + 연습 20장 (A4 22장) |
| 학기 화면 | 제목 옆 **학기 전체 인쇄** | 10회차 전부 (A4 220장) |

인쇄 창에서는 **용지 A4**, **여백 없음**, **배경 그래픽 인쇄 켜기**를 권합니다.
프린터 대신 `PDF로 저장`을 고르면 워크북 파일이 그대로 만들어집니다.

> 학기 전체 인쇄는 220장이라 시간이 꽤 걸립니다. 실수로 누르지 않도록 확인 창이 한 번 뜹니다.

## 7. 진행 상황 보기

- **학기 카드** — 그 학기에서 끝낸 장 수 (`40 / 200장`)
- **회차 목록** — 회차마다 끝낸 장 수 (`12 / 20장`)
- **DAY 목록** — 장마다 최고 점수. 90점 이상 받은 장은 초록색으로 바뀝니다

한 장을 여러 번 풀면 **가장 잘한 기록**이 남습니다.
기록은 지금 쓰는 브라우저에만 저장되고 어디로도 전송되지 않습니다.

## 8. 이럴 땐 이렇게

**코드를 넣었는데 안 들어가져요**
"이미 지난 N주차 코드입니다"라고 나오면 지난주 코드입니다. 블로그 댓글로 이번 주 코드를 문의해 주세요.
"코드가 맞지 않습니다"라고 나오면 오타일 가능성이 큽니다. 코드에는 헷갈리기 쉬운
`I` `O` `0` `1` 이 들어가지 않으니, 비슷하게 생긴 글자를 다시 확인해 보세요.

**매주 코드를 또 받아야 하나요**
네. 주차마다 코드가 달라서 일주일에 한 번은 새로 받으셔야 합니다.
그 주 안에서는 몇 번을 들어가도 다시 묻지 않습니다.

**풀던 기록이 사라졌어요**
기록은 브라우저마다 따로 저장됩니다. 다른 기기나 다른 브라우저에서 열었거나,
시크릿 모드로 열었거나, 브라우저 기록을 지우면 이어지지 않습니다.
휴대폰과 PC에서 번갈아 풀면 진행률도 따로 쌓입니다.

**학기 카드가 회색이고 눌리지 않아요**
아직 준비 중인 학기입니다. 문제 데이터가 준비되면 열립니다.

**풀던 자리로 바로 가고 싶어요**
화면마다 고유한 주소가 있습니다. 예를 들어 `…/#/s/3-1/4/2/B` 는
3학년 1학기 4회 DAY 2의 B입니다. 즐겨찾기에 넣어 두면 바로 열립니다.

**인쇄했더니 색이 안 나와요**
인쇄 창에서 **배경 그래픽 인쇄**가 꺼져 있는 경우입니다. 켜고 다시 인쇄해 보세요.

## 9. 알아두면 좋은 점

온라인 문제는 종이 워크북과 **같은 문제, 같은 순서**입니다.
집에서는 종이로, 밖에서는 휴대폰으로 같은 진도를 이어서 풀 수 있습니다.

정답은 파일에 적혀 있지 않고 화면에서 그때그때 계산해서 채점합니다.
그래서 문제와 정답이 어긋날 일이 없습니다.

학습 기록은 브라우저 안에만 저장되며 서버로 전송되지 않습니다.
이름이나 연락처 같은 개인 정보를 요구하지 않습니다.
